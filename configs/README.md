# Device Configurations

Running configs exported from Packet Tracer (`show running-config` on each device).

- `R1.txt`, `R2.txt`, `R3.txt` — core routers (OSPF, static default routes)
- `D1.txt`, `D2.txt` — distribution switches (inter-VLAN routing, ACLs, trunking)
- Access switch configs — VLAN assignment and port security
